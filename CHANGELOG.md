## [0.1.0] - 2026-08-09

### Added

- Initial scaffold: `wrap`/`unwrap` fixed-width reflow, `lint`/`detect` dialect validation
  against strict CommonMark, GitHub Flavored Markdown, and JIRA Cloud markdown.
- Symfony Console-based CLI, shipped as a standalone `.phar` built with Box.
